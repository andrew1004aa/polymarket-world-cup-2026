\section{Data}
\label{sec:data}

\subsection{Data sources and canonical trade sample}

This dissertation draws on three primary public data sources for trades,
prices, and match information, with Dune Analytics used separately for external
market-level count validation. Trade-level observations were collected directly from
the Polymarket Data API and constitute the sole canonical trade-level dataset.
After collection, independently obtained Dune Analytics market-level trade
counts were used solely to assess the completeness of the API extraction. No
Dune observations were incorporated into or used to modify the canonical
dataset.

Within the study window, the API returned 6,725,954 rows. Each complete API
object was serialised with keys in canonical order and hashed using SHA-256.
The first occurrence of each object was retained, while 222 later responses
that were identical to a previously retained complete object were removed.
These repeated deliveries affected 39 markets: none occurred within the same
checkpoint and all 222 occurred across checkpoints. This exact-response check
left 6,725,732 canonical Data API trade records. It was not transaction-hash
deduplication and did not aggregate records into inferred economic trades,
orders, or executions. Indeed, no transaction-hash deduplication or
economic-trade aggregation was applied.

The methodological observation unit is therefore a retained Data API trade
record. Collection requests explicitly set \texttt{takerOnly=true}. The API
does not provide a separate independent fill-level trade identifier, but every
retained record in this sample has a non-empty transaction hash and all
6,725,732 hashes are unique. This transaction-hash diagnostic describes this
sample; it was not used as a deduplication or execution-aggregation rule.

Completeness was assessed separately using Dune Analytics query 8139394 for
the 312 match contracts and query 8140259 for the 48 country outright
contracts; the local query exports were downloaded on 31 July 2026. Across all
360 markets, 350 API and Dune counts agreed exactly;
Dune reported one additional record in each of ten markets. The corresponding
totals were 6,725,732 canonical API records and 6,725,742 Dune records, an
aggregate difference of ten. Dune served only as an external market-level
count check and supplied no trade-level observations to the canonical or
regression datasets.

The observation window spans 2026-06-01T00:00:00Z to
2026-08-01T00:00:00Z, with the end point excluded. The final canonical sample
contains 6,725,732 retained Polymarket Data API trade records across 360 binary markets:
312 home-win, away-win, or draw contracts nested in 104 FIFA World Cup matches,
and 48 country outright-winner contracts.

Price data were collected separately from the Polymarket CLOB price-history
endpoint at one-minute fidelity. The associated price dataset contains
17,980,605 raw observations for the 720 corresponding YES and NO tokens, with
no interpolation or resampling. The endpoint documents each observation as a
timestamp and price value but does not identify that value as a contemporaneous
midpoint or pre-trade quote. The outcome is therefore described throughout as
a recorded-price adjustment, and the executed-trade-price robustness checks
provide a separate validation. Match schedules, actual kickoff information,
and outcomes come from the official FIFA workbook,
\texttt{world-cup\_2026.xlsx}, and its reviewed 104-event table. Dune query
8142697 was used only as an auxiliary mapping of those 104 matches; it was not
a trade-data source. These roles are distinct from the Polymarket CLOB
\texttt{/prices-history} source described above.

The public reproducibility repository contains the code and fixed research
materials described in Section~4.10:
\url{https://github.com/andrew1004aa/polymarket-world-cup-2026}.

\subsection{Sample separation principles}

Three separations are applied consistently to the canonical sample before it
is aggregated into any model-ready panel. First, match contracts and country
outright contracts are analysed as separate families throughout, because
their horizons, resolution timing, and information environments differ; no
result pools the two families. Second, match-market observations are split
by phase: pre-kickoff observations form the primary sample for H1, H2, H3a, H3b and RQ4,
post-kickoff/pre-resolution observations are analysed separately because
match events generate fundamental information, and trades at or after
recorded resolution are retained only in a method-neutral audit panel and
excluded from every model sample. The post-kickoff phase is not labelled
purely in-play because actual final-whistle timestamps are unavailable.
Third, trades within the same market and UTC minute are aggregated into a
single market-minute observation before any price response is calculated,
because the price-history endpoint has one-minute fidelity and several
trades can share the same observed price outcome.

The wallet-heterogeneity and whale samples share the same 2,395,771-action
evaluation window but classify wallets from different histories: the
high-activity proxy ranks wallets using only their own trailing or expanding
activity, whereas the whale proxy ranks wallets by cumulative gross USDC
across all 6,725,732 canonical trades in the full 360-market universe. The
two proxies are conceptually and operationally distinct (Section~\ref{sec:wallet-heterogeneity-design}, Section~\ref{sec:whale-wallet-design})
and are not interchangeable, even though both are evaluated over the same
action sample.

The 1,000-prior-trade eligibility rule limits the H2 conclusion to markets with
adequate observable trading history. Expanding history includes 252 markets and
excludes 60; rolling history includes 236 and excludes 76. Under expanding
history, included markets average 18,878 trades and \$4.76 million in recorded
volume, compared with 9,309 trades and \$1.60 million among excluded markets.
Their mean baseline probabilities are also higher (0.367 versus 0.196), and
their pre-kickoff analysis histories are longer (2,619 versus 1,473 observed
market-minutes). Rolling-history comparisons show the same pattern. Stage shares
are broadly similar, but the eligibility rule selects more active, longer-lived,
and generally higher-probability contracts; the findings are not generalised to
thin markets without sufficient prior history.
